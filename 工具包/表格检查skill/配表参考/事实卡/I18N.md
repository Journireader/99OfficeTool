# 事实卡：I18N / Prompt / TermLink

## 0. 元信息

- 源 Excel：`develop/system/I18N.xlsx`、`develop/system/Prompt.xlsx`、`develop/system/TermLink.xlsx`
- 最近验证：2026-06-07 / SVN r3895 / 只读抽样
- 状态：已验证导航；具体文案内容以源 Excel 当前行为准
- 第一参考：`系统/I18N.md`、`系统/战斗_I18N映射.md`、`约定/表字段索引.md`

## 1. 表事实

| 项 | 内容 |
|---|---|
| 表角色 | 表现表 / 玩家可见文案 |
| 结构 | `I18N.xlsx` 按业务拆成多个 `I18N#模块名` sheet，不是一张统一文案表 |
| 主键 | 各 `I18N#` sheet 的 `Key` |
| 语言列 | 常见为 `Lang#N.Name` + `Lang#N.Val` |
| TermLink | `TermLinkID` 被 I18N 富文本 `<link>ID</link>` 引用，名称 / 描述落 `I18N#TermLink` |

## 2. 字段语义

| 字段 | 语义 | 易误判 |
|---|---|---|
| `Key` | 文案 key 本体 | 不是中文正文 |
| `Lang#N.Val` | 指定语言正文 | 不作为跨表 key |
| 主表里的 `Name` / `Describe` / `NameID` / `DescriptionID` | 多数存 I18N key | 不能只看字段名判断落哪个 sheet |
| `Prompt*` sheet | 提示类文案承接 | 不等于普通 `I18N#` sheet |

## 3. 跨表引用

| 源字段 | 关系类型 | 目标表 / 字段 | 新增时动作 | 修改 / 删除时反查 |
|---|---|---|---|---|
| `Skill.Name` / `Skill.Describe` | I18N 文案 | `I18N#Skill.Key` | 基础 Skill 文案补 `I18N#Skill` | 查 Skill 当前引用和战斗 I18N 路由 |
| `Inscription.Name` / `Describe` | I18N 文案 | `I18N#Inscription.Key` | 铭文名称 / 品质描述补对应 key | 查 4 品质描述是否逐阶累加 |
| `Buff.Name` / `Describe` | I18N 文案 | `I18N#Buff.Key` | Buff 展示文案补 `I18N#Buff` | 查 Skill / Buff 效果链是否使用该 Buff |
| `Item.Name` / `Describe` | I18N 文案 | `I18N#Item.Key` | 道具名称 / 描述补 `I18N#Item` | 查 Item / Store / Reward 是否引用 |
| `<link>ID</link>` | 富文本词条 | `TermLink.TermLinkID` | 新增 TermLink 行和 `I18N#TermLink` | 查所有文案中该 link 是否仍有效 |

## 4. 玩家可见文案

| 场景 | 主表字段 | I18N / Prompt sheet | 禁止事项 |
|---|---|---|---|
| 基础技能 | `Skill.Name` / `Describe` | `I18N#Skill` | 铭文变体不要硬补到基础 Skill 文案 |
| 铭文 | `Inscription.Name` / `Describe` | `I18N#Inscription` | 不要把四阶描述混成一条 |
| Buff | `Buff.Name` / `Describe` | `I18N#Buff` | 不要拿内部备注当玩家文案 |
| 圣物 | `RelicBase` / `RelicLevel` 文案字段 | `I18N#Relic` | 等级描述和本体描述不要混 |
| 词缀 | `Affix.Name` / `Describe` | `I18N#Affix` | 不要落到 `I18N#Skill` |
| 提示 | `Prompt*` | 对应 `Prompt` sheet + `I18N#Prompt*` | 不要只补 I18N 不补 Prompt 行 |

## 5. 反向影响

| 改动类型 | 必查反向引用 | 必补支撑 | 阻塞 / 需确认 |
|---|---|---|---|
| 新增可见名称 / 描述 | 主表字段引用该 key 的行 | 对应 `I18N#` sheet | 不确定归属 sheet 时需确认 |
| 改 key | 所有源表和代码中旧 key | 新 key 行、删除 / 保留旧 key 策略 | 旧 key 仍被引用时阻塞 |
| 改正文 | 目标 key 所在 sheet | 多语言列是否同步 | 只改 zh-cn 时需确认多语言策略 |
| 新增富文本链接 | I18N 正文中的 `<link>` | `TermLink` + `I18N#TermLink` | TermLink 缺失时阻塞 |

## 6. 验收清单

- key 在正确 `I18N#` 或 `Prompt` sheet 命中。
- 主表字段引用的是 key，不是误填中文正文。
- Buff / Affix / Relic / Inscription / Skill 展示归属没有串 sheet。
- `<link>ID</link>` 有对应 `TermLink` 和 `I18N#TermLink`。
- `config_link_check.py` / `config_relation_profile.py` 的文案项无未处理缺口。
