- 源 Excel：`develop/system/SystemFunction.xlsx`、`Jump.xlsx`、`Window.xlsx`、`Guide.xlsx`、`AVG.xlsx`
- 最近验证：2026-06-07 / SVN r3895 / 只读抽样
- 状态：已验证导航；具体开放逻辑仍以源表、代码和需求确认为准
- 第一参考：`约定/表字段索引.md`、`约定/索引链检查.md`

## 1. 表事实

| 项 | 内容 |
|---|---|
| 表角色 | 通用支撑表 / 系统接入 |
| SystemFunction | 功能入口、名称描述、图标、解锁、排序 |
| Jump | 跳转目标与参数 |
| Window | 窗口资源 / 界面目标 |
| Guide / AVG | 引导和剧情支撑 |

## 2. 跨表引用

| 源字段 | 关系类型 | 目标表 / 字段 | 新增时动作 | 修改 / 删除时反查 |
|---|---|---|---|---|
| `SystemFunctionID` | 入口 | `SystemFunction.SystemFunctionID` | 补入口行 | 查 Guide / Jump / Condition |
| `UnlockCondID` | 条件 | `Condition.ConditionID` | 补条件行 | 查入口显隐和提示 |
| `JumpID` | 跳转 | `Jump.JumpID` | 补 Jump 行 | 查按钮 / 任务 / 道具跳转 |
| `WindowID` | 窗口 | `Window.WindowID` | 补 Window 行 | 查 Jump / 资源 |
| `PromptID` | 提示 | `Prompt` | 补 Prompt / I18N | 查失败提示 |

## 3. 禁止推断

- 有 `WindowID` 不等于系统已开放。
- 有 `JumpID` 不等于按钮会展示。
- 有 `SystemFunction` 不等于新手引导已接入。
- 入口相关改动通常需要 `Condition`、`I18N`、`Prompt`、`Picture` 一起查。

## 4. 反向影响

| 改动类型 | 必查反向引用 | 必补支撑 | 阻塞 / 需确认 |
|---|---|---|---|
| 新增系统入口 | SystemFunction / Jump / Window / Condition | I18N、Picture、Prompt | 是否需要 Guide 需确认 |
| 改 JumpID | 所有引用旧 JumpID 的道具、任务、按钮 | Jump 行 | 旧引用未同步时阻塞 |
| 改 WindowID | Jump / SystemFunction / Guide | Window 资源 | 客户端窗口不存在时阻塞 |
| 改开放条件 | SystemFunction / 活动 / 任务 | Condition / Prompt | 条件文案缺失时需确认 |

## 5. 验收清单

- 入口、跳转、窗口、条件、提示各自命中。
- 玩家可见名称 / 描述 / 提示补 I18N 或 Prompt。
- 需要新手引导时已查 Guide / AVG。
- 不需要接入的支撑表写明“不适用理由”。
