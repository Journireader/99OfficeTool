- 第一参考：`约定/索引链检查.md`、`约定/表字段索引.md`

## 1. 表事实

| 项 | 内容 |
|---|---|
| 表角色 | 表现表 / 资源承接 |
| 强链字段 | `PictureID`、`IconPath`、`BackgroundImageID`、`AudioID`、`WindowID` |
| 上下文字段 | `ResID`、`ModelID`、`EffectID` 必须结合表 / sheet / 字段全名判断 |
| 怪物资源链 | `Enemy.ResId -> RoleRes#MonsterRes -> NudeModel#MonsterModel` |

## 2. 跨表引用

| 源字段 | 关系类型 | 目标表 / 字段 | 新增时动作 | 修改 / 删除时反查 |
|---|---|---|---|---|
| `PictureID` / `*PictureID` / `IconPath` / `BackgroundImageID` | 资源表现 | `system/Picture.xlsx#Picture.PictureID` | 补 Picture 行或复用已有 ID | 查所有引用该 PictureID 的表 |
| `AudioID` | 资源表现 | `system/Audio.xlsx#Audio.AudioID` | 补 Audio 行 | 查触发场景和音量配置 |
| `WindowID` | 入口 / 表现 | `system/Window.xlsx#Window.WindowID` | 补 Window 行或复用 | 查 Jump / SystemFunction 引用 |
| `SpecialEffectID` | 资源表现 | `system/SpecialEffect.xlsx#SpecialEffect` | 补特效路径和挂点 | 查 SkillDirector / Buff / 表现链 |
| `Enemy.ResId` | 怪物资源 | `role/RoleRes.xlsx#MonsterRes.MonsterResID` | 补 MonsterRes / MonsterModel | 查 Enemy、场景和怪物技能链 |

## 3. 禁止推断

- `ResID` 不是全局外键。活动 UI 资源、战斗实体资源、掉落物资源不是同一条链。
- `PictureID` 命中 Picture 只说明配置表有图片记录，不说明客户端资源文件一定存在。
- `WindowID` 命中 Window 不代表入口已经开放，还要查 `SystemFunction` / `Jump` / `Condition`。
- `SpecialEffectID` 命中特效表不代表 Trigger 帧点或挂点正确，还要查 `SkillDirector` 或具体使用表。

## 4. 反向影响

| 改动类型 | 必查反向引用 | 必补支撑 | 阻塞 / 需确认 |
|---|---|---|---|
| 新增图标 / 图片 | 主表引用字段、PictureID 是否重复 | `Picture.xlsx` | 资源文件路径未知时需确认 |
| 改资源 ID | 所有旧 ID 引用 | 新 ID 行 | 旧 ID 仍被引用时阻塞 |
| 改窗口 / 跳转表现 | `Jump`、`SystemFunction`、`Guide` | `Window` / `Jump` | 入口逻辑未知时需确认 |
| 改怪物资源 | `Enemy`、`Scene`、`RoleRes`、`NudeModel` | MonsterRes / MonsterModel | 模型挂点缺失时阻塞 |

## 5. 验收清单

- 直接外键字段命中目标表现表。
- `ResID` / `ModelID` 已按上下文分流。
- 入口类改动同步查 `Window` / `Jump` / `SystemFunction` / `Condition`。
- 怪物资源链至少查到 `Enemy -> MonsterRes -> MonsterModel`。
- 资源文件真实存在性若未检查，交付必须标“未检”。
