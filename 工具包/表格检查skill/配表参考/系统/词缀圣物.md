## 词缀

- 总数：当前 26 条（历史上规划"5 旧 + 25 新"共 30 条，实际以 `Affix.xlsx` 行数为准）
- 每个词缀通过 SkillIDs 数组挂载多个被动技能（SkillID 前缀 32）
- AffixID = 3（中毒）和 AffixID = 5（护盾）描述互换已修正

### 表串联

```
Affix.SkillIDs（数组）→ 多个 Skill（一组被动技能共同实现词缀效果）
Affix.Name / Describe → I18N#Affix（玩家看到的词缀名称和描述）
```

一个词缀的完整效果由 SkillIDs 中的多个技能共同实现。这些被动技能**不配 I18N#Skill**，展示走 I18N#Affix。

## 圣物

- 4 部位：誓印(01) / 战刃(02) / 项圈(03) / 鞭子(04)
- 每部位 10 件圣物（序号 01-10）
- 每件 6 个效果槽 + 99 个技能组容量
- 誓印（旧名护符）已有历史配置记录；新任务按当前源表和术语对照表复核。
- `RelicLevel.EffectDes` 是圣物每级升级收益展示，必须按该等级实际 Skill / Buff 配置写当前等级数值；不要只写泛描述。

### 圣物的技能挂载

一件圣物有等级效果、套装效果和属性池三类配置。等级效果与套装效果由多个 SkillID 组合实现（和全游戏逻辑一致：多个 SkillID 才构成一个完整效果）；属性池不是 SkillID，而是 `RelicPool.PoolID`。

| 类型 | TT 范围 | 说明 | 引用来源 | I18N 描述 |
|------|---------|------|---------|-----------|
| 等级效果 | TT=01-10 | 随圣物升级逐级解锁 | RelicLevel.Effect | RelicLevel.EffectDes → I18N#Relic |
| 属性池 | PoolID 1001-1099 / 2001-2099 | 冰痕 / 火痕随机属性 | RelicBase.IcePool / FirePool → RelicPool.PoolID | 无独立 I18N |
| 套装效果 | TT=13-16 | 凑套触发 | RelicBase.ThreeIceID / ThreeFireID / TwoIceID / TwoFireID | RelicBase.*Des → I18N#Relic |

一件圣物关联的 SkillID 数量 = 等级效果 + 套装效果的技能组数，实际可达几十个。等级效果和套装效果的描述都指向 I18N#Relic，但 key 格式不同；属性池无独立 I18N。这些被动技能**不配 I18N#Skill**。

### 表串联

```
RelicBase.IcePool / FirePool → RelicPool（冰痕 / 火痕属性池）
RelicBase.Three* / Two*ID → Skill（套装被动技能）
RelicBase.Name / *Des → I18N#Relic（圣物名称和套装效果描述）

RelicLevel.Effect → Skill（等级效果技能）
RelicLevel.EffectDes → I18N#Relic（等级效果描述）
```

## 配置决策记录

- 词缀效果使用被动技能挂载，不直接写在 Affix 表的效果字段
- 圣物等级描述使用独立 I18N Key（每级一条），不复用技能描述；描述正文按每级实际收益写数值（百分比、固定概率、持续 / 冷却、层数 / 次数等玩家需要比较的展示值），但不写 EffectID、TypeData、公式字段名等内部实现细节
- I18N 圣物被动已从 I18N#Skill 迁至 I18N#Relic（250 条 EffectDes）
- I18N 词缀描述已从 I18N#Skill 迁至 I18N#Affix
