# 配表事实卡模板

事实卡给 agent 和配表人员做快速裁决用。它不替代源 Excel，也不替代系统专题长文；它只回答“这张表 / 这个字段族 / 这条链路在本次任务里怎么判断”。

一张事实卡建议对应一个 workbook#sheet、一个字段族，或一条高风险引用链。不要把完整系统都塞进一张卡。
