# 配表产出规范

## 产出方式

- 复制源表完整副本（所有 sheet、所有数据、所有结构原样保留）
- 在副本上新增或修改内容，原有数据不动

## 改动标记

所有本次新增或修改的单元格，统一标记为**黄底黑字下划线**。原有数据不动、不标记。

## 枚举格式

枚举值必须用 `[枚举类型名]枚举值名` 格式。

## 数据质量

数据要有实际游戏意义，不要填 xxx 或 test。

## 工具边界

评审副本可以使用能保留完整 workbook 结构并标记改动的工具生成，但正式源表回填不能直接复用评审副本。

正式源表回填只写最终数据，不带黄底黑字下划线标记；格式敏感源表优先做最小范围 value / XML 补丁。涉及公式、富文本表头、sharedStrings、插列、删行或高层 Excel 库保存风险时，按 `约定/配表执行经验.md` 的 xlsx 写入边界处理。

## QA 自检清单（产出后必过）

任何配表产出（特别是新系统或多表联动）完成后，按以下 4 大类逐项核对，避免高频漏项：

| 类别 | 检查对象 | 高频漏项 |
|------|---------|---------|
| 文案 | I18N、Prompt | 1. 名称/描述/提示语新增了，I18N 对应 sheet 没补 Key<br>2. 引导/反馈提示没补到 Prompt.xlsx |
| 接入 | Condition、SystemFunction、Guide、Jump | 3. 显示/解锁条件没补到 Condition.xlsx<br>4. 入口/跳转/引导没补到 SystemFunction / Guide / Jump |
| 结算 | Event、SystemEvent、Item | 5. 触发逻辑加了但 battle/BattleEvent.xlsx 或 system/SystemEvent.xlsx 没补齐<br>6. 奖励落到 Item.xlsx 时，文案/资源/背包承接没跟上 |
| 资源 | 图/音频/特效/窗口对应资源表 | 7. 引用了图/音频/特效/窗口，但对应资源表没补<br>8. 改了主键/外键/编号规则，但没检查所有引用表 |

主键变更时必查所有引用表是 8 项里成本最高、最易遗漏的一项——任何 ID 段调整后单独走一遍跨表 grep。
