# 表到专题索引

用于 agent 快速从表名定位到第一份参考、事实卡和联查方向。这里是导航，不是字段事实本体；当前数据仍以源 Excel 和对应事实卡 / 系统专题为准。

- 最近刷新：2026-09-21 / SVN r6595 / 导航更新；全量 sheet 边界见 `约定/全表快照.md`
- 当前正式 `develop` xlsx 数：92
- 字段级深读：`约定/表字段索引.md`
- 全量 sheet 快照：`约定/全表快照.md`
- 事实卡模板：`约定/事实卡模板.md`

## 使用方式

1. 用表名、sheet 名或任务关键词在本文件搜索。
2. 先读“第一参考”和“事实卡”。
3. 如果是字段级 / 参数级 / 跨表引用判断，再读“联查参考”。
4. 若状态为“部分确认 / 需确认 / 历史”，不能直接作为源表写入依据。

状态口径：`已验证导航` 只表示 workbook 已纳入全量盘点且入口可达，不表示字段和业务语义已经补全；`部分确认` 表示已知结构或部分链路，但仍有明确缺口。只有状态文字明确写出“字段 / 关系 / 消费链已验证”的表，才可以按对应已验证范围独立阅读；数值定案、线上生效与未写明的业务规则仍需另证。
